`Inter-Regular.ttf`, `Inter-SemiBold.ttf` and `Inter-Bold.ttf` are static
instances of the upstream variable font at optical size 14 and weights
400, 600 and 700 respectively.

`InterExportOblique-Italic.ttf` is a derivative of the regular instance, named
Inter Export Oblique. Its outlines are slanted with x' = x + 0.25y; advance
widths are unchanged. This reproduces the synthetic oblique style in the
original Notion PDF. Typst identifies this font family as `Inter Export`.
